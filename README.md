# Lab Projects.

## Estudos

O objetivo deste repositório é armazenar e organizar diferentes projetos e estudos relacionados ao desenvolvimento web e software.

Nem todos os projetos estão finalizados ou funcionando perfeitamente, muitos são apenas registros de estudo, testes de conceitos ou implementações em andamento. A ideia principal é documentar a evolução e manter tudo organizado em um só lugar.
